# Changelog

## 0.7.0

- Switch between Swedish and English in the picker; remember the choice across launches.
- Translate profile editing, import/export, password dialogs, certificate prompts and helper messages.
- Preserve user-entered profile data and keep the language menu accessible in small windows.
- Share one translation catalog between QML and Python, with language regression tests.

## 0.6.1

- Package the plugin for Git-based installation and downloadable ZIP releases.
- Check dependencies before setup and support running setup inside an installed checkout.
- Add reversible shortcut integration, installation tests and release packaging.

## 0.6.0

- Selective JSON export and import without passwords.
- Preview, keep/replace choices and a backup before import changes.

## Earlier development

- Searchable profiles, customer labels and favorites in a tiled QML picker.
- FreeRDP sessions on separate workspaces, contextual Alt+Tab and resolution choices.
- Optional Secret Service password storage and explicit certificate confirmation.
